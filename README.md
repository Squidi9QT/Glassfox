# Glassfox

Сделал себе Firefox в стиле Apple. Тут две части, они ставятся отдельно, так
что можно взять только одну.

- **Тема** (`theme/`) меняет вкладки сбоку и группы: капсулы вместо кружков,
  мягкие тени, плавные анимации.
- **Расширение** (`extension/`) добавляет кнопку, где собраны все вкладки и
  любимые сайты, и плеер со спокойной музыкой в боковой панели.

Нужен Firefox 115 или новее.

## Как подключить тему

Скрипт написан под macOS.

1. Откройте в Firefox `about:config` и согласитесь с предупреждением.
2. Найдите `toolkit.legacyUserProfileCustomizations.stylesheets` и поставьте
   `true`.
3. В папке проекта запустите:

   ```bash
   bash theme/install.sh
   ```

4. Перезапустите Firefox.

Скрипт кладёт `userChrome.css` в папку `chrome` вашего профиля. Если там уже
был свой файл, он сохранится рядом как `userChrome.css.bak`. Чтобы всё
вернуть, удалите `userChrome.css` из этой папки (путь скрипт пишет в конце) и
перезапустите Firefox.

На Windows и Linux скрипт не сработает, но файл можно положить руками: путь к
профилю есть в `about:support` в строке «Папка профиля», внутри создайте папку
`chrome` и скопируйте туда `theme/userChrome.css`.

## Как подключить расширение

**Попробовать.** Откройте `about:debugging#/runtime/this-firefox`, нажмите
«Загрузить временное дополнение…» и выберите `extension/manifest.json`. Так
оно работает до закрытия Firefox, потом его надо загрузить снова.

**Поставить насовсем.** Firefox насовсем ставит только подписанные
расширения. Подпись бесплатная, публиковать в каталоге не обязательно:

1. Соберите архив:

   ```bash
   bash build.sh
   ```

   Рядом появится `glassfox.zip`, в нём только файлы расширения.
2. Зайдите на [addons.mozilla.org/developers](https://addons.mozilla.org/developers/),
   нажмите «Submit a New Add-on» и выберите «On your own».
3. Загрузите `glassfox.zip`. Через пару минут можно скачать подписанный
   файл `.xpi`.
4. Перетащите `.xpi` в окно Firefox.

## Как пользоваться

**Кнопка на панели** (синяя иконка):

- Во вкладке «Вкладки» видно все вкладки из всех окон. Можно искать,
  стрелками ↑↓ и Enter перейти, крестиком закрыть. Вкладка, где играет звук,
  помечена значком.
- В «Сайтах» лежат ваши частые сайты. Если сайт уже открыт, расширение
  переключит на его вкладку, а не откроет новую. «Добавить текущую вкладку»
  кладёт туда открытый сайт.
- Tab в поиске переключает «Вкладки» и «Сайты».
- Внизу есть мини-плеер: играть или пауза, и кнопка, которая открывает плеер
  сбоку.

**Плеер сбоку** (иконка ноты в боковой панели):

- Шесть станций спокойной музыки без рекламы с SomaFM: эмбиент, джаз, lo-fi.
- Музыка играет в фоне, даже если закрыть панель и все вкладки.
- Пока играет, на кнопке расширения горит ♪.
- Через «Добавить свою станцию» можно вставить ссылку на любой поток радио
  (mp3 или aac).
